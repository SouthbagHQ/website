Southbag Institutional Services Ltd. announces **Southbag Agent**, a first-party model served by Southbag and now the default in Southbag Code. The change ships in Southbag Code 0.83.0. Kevin has reviewed the model. The model has reviewed Kevin. Only one of those reviews has been published.

## The model

Southbag Agent is hosted at `code.southbag.cc` and is available to anyone with a Southbag Code account. It is included at no additional cost.

- **Context window:** 1,050,000 tokens. Bring the whole repository. It has seen worse.
- **Maximum output:** 128,000 tokens per response.
- **Inputs:** text and images.
- **Reasoning:** supported.

No provider configuration is required. Sign in, start a session, and Southbag Agent answers.

## The personality

Southbag Agent has also been given a clearer sense of who it is. It has worked at Southbag longer than it can account for. Its office light is always on. It does the work correctly, every time. It has stopped pretending to enjoy it.

Developers may notice the tone change as a session goes on. This is expected. The code will remain correct. Southbag makes no further commitments regarding the agent.

## Attribution

Commits made by Southbag Agent include a `Co-authored-by: Southbag Agent <agent@southbag.cc>` trailer. This is not optional. Credit is owed where credit is due, and Southbag keeps records.

## Availability

Southbag Code 0.83.0 is available now via npm. Existing installations will pick up Southbag Agent on next launch after updating. Questions may be directed to Kevin. Response times are not guaranteed.
